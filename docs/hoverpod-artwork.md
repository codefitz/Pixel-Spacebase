# Hoverpod artwork refresh

The Hoverpod is a rounded silver/navy maintenance capsule with a blue canopy, orange hazard tabs and twin cyan hover jets. The captain, commander, shapeshifter and DM3000 heads are copied from their existing unarmoured sprites into the intact pod's cockpit. Damaged/death poses show cracked and collapsed wreckage without a pilot overlay.

The built-in image tool generated the vehicle artwork. `scripts/InstallHoverpodArtwork.java` packs the 21 poses into the existing 12x15 logical-pixel frames, enlarged four times with nearest-neighbour blocks. Run it with the generated source PNG and cockpit top row `4` as arguments. The inventory icon is derived from the empty pod's idle pose and installed at the unchanged item slot 163.

Final standalone art is `core/src/main/assets/hoverpod.png` and `core/src/main/assets/hoverpod_animations.png`; the game uses their copies installed in `items.png` and tier-four rows of all four hero atlases. The preview in `docs/hoverpod-preview.png` shows captain, commander, shapeshifter and DM3000 in order.

The existing 4/3 on-level scale remains unchanged, so the Hoverpod stays smaller than the Heavy Loader. No protection, integrity, explosion, repair, reinforcement, vacuum or gas rules changed. Before-art backups are saved as `docs/sprite-backups/*-before-hoverpod-reskin.png`. The installer checks every pixel outside the Hoverpod row and item slot against these backups.
